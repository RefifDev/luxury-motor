# luxury-motor

Fictional luxury car dealership website. Multi-page site with sliders, car specs, and detailed product pages. Built with HTML, CSS and vanilla JS. (school project)

## Features
- Multi-page site
- Image slider with JS
- Detailed car spec pages
- Responsive design

## Stack
HTML · CSS · Vanilla JS
